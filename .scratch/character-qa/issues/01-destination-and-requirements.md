# 목적지와 기본 요구사항 정하기

Type: grilling
Status: resolved

## Question

추가 요구사항 "캐릭터가 마우스를 따라오면서, PPT의 내용을 읽어 주고, 그에 맞게 LLM으로 질의응답까지 가능한 프로그램"의 목적지는 무엇이고, 기능의 큰 틀은 어떻게 되나?

## Answer

2026-10-16 지도를 그리며 발표자(사용자)와 네 라운드에 걸쳐 정했다.

### 목적지와 범위
- 결과물은 **구현용 기획서**다. 기존 `PROMPT.md`처럼 저장소에 둔다. 기획이 끝나면 곧바로 구현한다.
- 새 프로그램이 아니라 기존 `ppt_reader`를 **확장**한다. `slides.py`, `tts.py`, `link.py`를 그대로 쓴다.
- 장면: 교실 발표. 캐릭터가 슬라이드를 읽고, 발표 뒤 **청중의 질문**에 답한다.
- 사용할 PC는 **인터넷에 연결**된다. **Windows와 macOS를 모두** 지원한다.

### 사람과 질문
- **발표자**는 사람(조작하는 학생)이고, **캐릭터**와 구분한다.
- 질문은 **발표자가 키보드로** 대신 입력한다. 마이크 입력은 하지 않는다.
- 질의응답은 발표자가 **버튼으로 시작**한다. 자동 시작은 본질이 아니다.
- 답은 **PPT를 먼저 근거로** 삼고 **일반 지식으로 보충**한다. 보충한 부분은 자료에 없다고 밝힌다.
- 답은 **강아지 머리 위 말풍선**과 음성으로 함께 낸다.
- 설정에 **개인 지침**을 적으면 답에 반영한다.

### 그림 캡션
- 슬라이드 속 그림은 별도 티켓으로 다룬다. 방향: LLM이 그림을 보고 **캡션**을 만들고, 그 캡션을 답의 근거에 넣는다.

### LLM
- **Claude, OpenAI, Gemini**를 모두 지원한다. 설정에서 **하나를 골라** 질의응답과 캡션에 함께 쓴다.
- 제공자마다 **기본 모델**이 있고 바꿀 수 있다. 현재 쓸 수 있는 모델을 조사해 목록에 넣는다.
- **생각 깊이**: 질문창과 함께 뜨는 **알약(pill) 모양 위성 버튼**이다. 누를 때마다 low → mid → high … 로 돌아가며, 현재 단계를 글자로 보여 준다.
- API 키는 사용자가 설정 화면에 넣고 **설정 파일에 그대로** 저장한다.

### 음성
- 답도 기존 **운영체제 음성**으로 읽는다. 클라우드 음성은 나중에 선택지로 더할 예정이라 이번 범위 밖이다.
- **배속**은 위성 버튼 하나로 둔다. 누를 때마다 x1 → x1.5 → x2 → x5로 바뀐다.

### 화면
- **기존 창은 없앤다.** 화면에는 캐릭터와 원 버튼만 둔다.
- **캐릭터**: 귀여운 **붉은 목띠를 맨 도트 강아지**다. 움직이는 애니메이션이고, 이동·생각·엎드림 같은 자세가 있다. 그림은 **코드로 생성**한다. 마우스 커서의 **오른쪽 아래**에 붙어 따라다닌다. 읽는 단위는 슬라이드 한 장이다.
- **원 버튼**: 화면 오른쪽 아래 구석의 **파란 원**이다. 평상시와 읽을 때 서로 다른 **파동 애니메이션**을 보인다. 파동은 장식이지만, 말하는 동안에는 GPT 음성 모드처럼 **목소리의 성격을 반영**한다.
  - 기본은 **주 모니터**에 둔다. 설정에서 모니터를 찾아 다른 모니터로 옮길 수 있다.
- **위성 버튼**: 원 버튼을 누르면 둘레에 펼쳐지고, 몇 초 동안 아무것도 누르지 않으면 접힌다. 버튼은 [질문하기] [읽기/정지] [배속] [설정] [끝내기]다.
- **질문창**: [질문하기]를 누르면 원 버튼 **왼쪽**에 펼쳐진다.
- 파일 열기와 PowerPoint 연동은 **설정 창**으로 옮긴다. 슬라이드 목록과 대본 고치기는 설정 창 안의 **대본 화면**으로 옮긴다.
- 화면 툴킷은 **tkinter를 먼저 검토**한다. 필요한 효과가 안 되면 다른 툴킷(예: Qt)을 허용한다. 의존성과 실행 파일이 커지는 것은 감수한다.
