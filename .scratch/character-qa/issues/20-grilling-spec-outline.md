# 기획서의 위치와 목차 정하기

Type: grilling
Status: resolved

## Question

이 지도의 목적지인 **구현용 기획서**를 어디에, 어떤 목차로 쓰나? 지금까지의 결정은 각 일(`.scratch/character-qa/issues/`)과 시제품 브랜치(`prototype/*`), 조사 브랜치(`research/*`)에 흩어져 있다.

정할 것:
- **위치와 이름**: 저장소의 어디에 두나(예: 기존 `PROMPT.md`를 고치나, 새 파일인가). 한 파일인가, 여러 파일인가.
- **목차**: 구현자가 순서대로 따라갈 수 있는 차례. 화면별인가, 모듈별인가, 구현 단계별인가.
- **근거 연결**: 조사 문서와 시제품을 기획서에서 어떻게 가리키나. `research/*`, `prototype/*` 브랜치를 main에 합치나, 필요한 문서만 옮기나.
- **`.scratch/`와 `CONTEXT.md`**: 기획 기록(`.scratch/`)과 용어집(`CONTEXT.md`)을 커밋하나, 기획서로 옮기고 지우나.
- **구현 단계**: 기획서에 구현 순서(예: 1단계 음성 흐름, 2단계 강아지와 원 버튼, …)를 넣나.

## Answer

- **위치, 이름, 형식**: 저장소 루트에 `PROMPT-character-qa.md` 한 파일로 쓴다. 형식은 `PROMPT.md`와 같지만, 처음부터 다시 만드는 프롬프트가 아니라 **지금 저장소를 확장하는** 프롬프트다. 사람이 읽어도 되고 코딩 에이전트에게 그대로 넘겨도 된다. `PROMPT.md`(처음부터 다시 만들기)는 고치지 않는다(발표자).
- **목차**: `PROMPT.md`의 뼈대를 따르고 이번 결정으로 채운다.
  1. 역할, 배경(교실 AI 발표자), 목표, 범위 밖
  2. 제약: Python 3.10+, PySide6 6.11.x, 두 운영체제, 키는 평문, 오션·코랄
  3. 화면별 명세: 강아지, 원 버튼 묶음(원 버튼, 위성 버튼 다섯, 질문창, 생각 깊이, 알림 줄), 말풍선, 설정 창, 대본 창. 수치와 색까지 적는다.
  4. 흐름: 대본 읽기와 자동 발표, 질의응답, 캡션, 오류 반응
  5. 모듈별 명세: `session`, `voice/`, `llm/`, `qa`, `captions`, `settings`, `ui/`. 스레드와 설정 파일을 포함한다.
  6. 화면 문구: 강아지가 하는 말, 알림 줄, 안내문
  7. 시험: 자동 테스트와 사람 확인표(부록)
  8. 함정: 조사에서 나온 것(EMF 판별, SAPI x5의 지속 플래그, `.app` 포장 등)
  9. 작업 순서(아래 구현 단계), 완료 기준, 보고 형식
- **근거 연결**:
  - 조사 문서 여섯 개는 기획서와 함께 main의 `docs/research/`로 옮긴다.
  - 시제품 세 개(`prototype/dog-sprites`, `prototype/orb`, `prototype/settings`)는 브랜치에 두고, 기획서에 "브랜치@커밋"과 꼭 필요한 수치만 옮겨 적는다.
  - 강아지 스프라이트 생성기는 구현 1단계에서 main의 `tools/`로 정식으로 옮긴다.
- **기획 기록과 용어집**: `.scratch/`와 `CONTEXT.md`를 기획서와 함께 main에 커밋한다.
- **구현 단계**: 각 단계는 pytest 통과와 그 단계의 확인표로 끝난다.
  1. 뼈대: Qt 앱 시작, `settings`(옛 설정 옮기기), `session`(기존 흐름 시험 옮기기), 스프라이트 PNG, `--self-check`, macOS 보조(pyobjc), 빌드 서버(저장소 공개 전 확인 포함). macOS는 빌드 서버로만 확인할 수 있으므로 이 길을 먼저 뚫는다. 끝 확인은 두 운영체제 빌드와 macOS 화면 찍기다.
  2. 음성 흐름: `voice/` 전체, 대본 읽기와 자동 발표를 새 흐름으로 옮기기
  3. 강아지와 원 버튼: 따라가기, 자세, 파동, 위성 버튼, 알림 줄
  4. 질의응답: `llm/`, `qa`, 질문창, 생각 깊이, 말풍선 스트림, 오류 반응
  5. 설정 창과 대본 창, 캡션
  6. 넘기기: `licenses/`, 안내문, Windows 사람 확인표, `README.md` 고치기
