# 클라우드 음성을 목소리 엔진으로 넣기

Type: grilling
Status: resolved
Blocked by: 22

## Question

2026-10-17 발표자가 1단계를 본 뒤 요청했다. "목소리 재생 시 운영체제별 기초 모듈 말고 일레븐랩스나 gpt-live 같은 API도 지원하게 해 달라. 설정에서 고르고, 그 API를 고르면 설정에서 API 키를 넣을 수 있게."

처음 지도에서는 클라우드 음성 합성을 범위 밖으로 두고, 음성 엔진을 나중에 끼울 수 있게 경계(`voice/engines.py`)만 두었다. 이 요청으로 범위에 넣는다. 정할 것:
- 어떤 소리(대본, 답)에 쓰나
- 실패했을 때
- 제공자 목록
- 비용과 지연(저장, 미리 합성)
- 키 칸
- 기본 모델, 배속(x1.5·x2·x5), 낱말 시각, 소리 형식 — [클라우드 음성 API 조사](22-research-cloud-tts.md) 결과를 보고 정한다

## Answer

클라우드 음성을 목소리 엔진으로 넣는다. 제공자는 **ElevenLabs와 Gemini**다(OpenAI는 뺌). 근거: [클라우드 음성 API 조사](22-research-cloud-tts.md), `docs/research/cloud-tts.md`.

- **엔진**: 운영체제 음성(기본), ElevenLabs, Gemini 중 설정에서 하나를 고른다. 대본 읽기와 질의응답 답에 같은 엔진을 쓴다.
- **OpenAI를 뺀 까닭**: 발표자가 말한 "gpt-live"는 OpenAI의 GPT-Live(`gpt-live-1`)로, 실시간 대화 전용이라 주어진 글을 읽는 기능이 없다. OpenAI의 음성 합성 모델(`tts-1`, `tts-1-hd`, `gpt-4o-mini-tts` 스냅숏)은 2027-01-06에 모두 종료되고(2026-10-01 공지), 대체로 권한 `gpt-realtime-2.1-mini`는 대화 모델이라 대본을 글자 그대로 읽는다는 보장이 없다.
- **키**: ElevenLabs 키는 목소리 카드에 따로 둔다. Gemini 음성은 질의응답의 Gemini 키를 함께 쓴다(회사가 같으면 키 하나, 한쪽에서 고치면 다른 쪽도 바뀜). 키 확인은 질의응답과 같은 방식이다. ElevenLabs는 `GET /v2/voices?page_size=1`로 확인한다.
- **배속**: 클라우드 음성은 늘 x1로 한 번만 합성해 저장하고, x1.5·x2·x5는 재생할 때 음높이를 지키며 늘인다. 배속을 바꿔도 다시 합성하지 않는다. 운영체제 음성은 지금 결정 그대로다.
- **낱말 시각**: ElevenLabs는 글자마다 시각을 주는 `/with-timestamps`를 쓴다. Gemini는 시각을 주지 않아 글자 수로 어림한다(macOS `say`와 같음).
- **실패**: 그 문장부터 운영체제 음성으로 이어 읽고 알림 줄로 알린다. 문장 하나의 합성이 8초 안에 끝나지 않으면 실패로 본다. 인터넷 끊김·시간 초과는 다음 장이나 다음 답에서 클라우드를 다시 시도하고, 키 문제·요금 한도는 설정에서 키를 다시 확인할 때까지 운영체제 음성으로 둔다.
- **저장과 미리 합성**: 대본 소리는 앱 폴더 `voice_cache/`에 엔진·모델·목소리·글(앞뒤 문장 포함)의 해시로 저장해 다시 쓴다. 모두 합해 500MB를 넘으면 오래된 것부터 지운다. 파일을 열면 대본 전체를 뒤에서 미리 합성하고, 대본을 고치면 그 장만 다시 만든다. 진행은 설정 창 목소리 카드에 보이고, 실패는 거기에만 알린다. 질의응답 답은 그때그때 합성하고 저장하지 않는다.
- **기본값**: ElevenLabs 모델 `eleven_multilingual_v2`(다른 선택지 `eleven_flash_v2_5`, `eleven_v4`), 목소리는 계정 목록을 불러와 고르고 처음에는 첫 목소리(기본 목소리가 2026-12-31에 사라지므로 id를 코드에 넣지 않음). Gemini 모델 `gemini-3.8-flash-tts`, 목소리 `Kore`.
- **설정 화면**: 목소리 카드 맨 위에 "목소리 엔진" 단추 묶음. 엔진에 따라 그 아래 목소리 목록, 모델, 키 칸, [들어 보기], 미리 만들기 진행이 바뀐다. ElevenLabs 무료 등급(한 달 약 1만 자) 안내를 한 줄 둔다.
