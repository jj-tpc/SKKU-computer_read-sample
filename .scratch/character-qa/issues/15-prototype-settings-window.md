# 설정 창 구성 정하기

Type: prototype
Status: resolved
Blocked by: 10, 11

## Question

설정 창(대본 창 포함)을 Qt로 새로 짤 때([GUI 툴킷 결정](09-grilling-gui-toolkit.md)), 무엇을 어디에 어떻게 두나? 오션·코랄 컨셉으로 꾸민다.

들어갈 것:
- 기존 설정: 읽을 내용, 목소리, 출력 장치, 자동 발표, 쇼에서 바로 읽기
- 파일 열기, PowerPoint 연동
- 대본 창: 슬라이드 목록과 대본 고치기, 슬라이드마다 캡션 보기·고치기, 캡션 진행 상황·멈추기·다시 만들기([캡션 결정](11-grilling-captions.md))
- 캡션 켜고 끄기(기본값 꺼짐)
- LLM 제공자·모델·API 키, 개인 지침
- 상태 표시: 키 확인 결과(키 칸 옆), PowerPoint 연동 상태(연동 칸), 캡션 진행 상황과 실패(대본 창)([오류 반응 결정](18-grilling-error-reactions.md))
- 원 버튼의 모니터: 쇼가 뜬 모니터 따라가기 또는 모니터 고정
- 강아지 고르기: 시바, 비숑, 비글(기본값 포함), 강아지 보이기 켜고 끄기([커서 따라가기 결정](14-grilling-cursor-follow.md))
- 음성: 목소리, 출력 장치는 기존과 같다. 배속은 원 버튼의 위성 버튼에서 바꾼다([목소리를 따라가는 방식 결정](10-grilling-voice-reactive-motion.md)).

정할 것: 탭이나 쪽 나누기, 항목 순서, 적용·취소 방식(기존 화면처럼 적용·취소가 있나), 처음 실행할 때 키와 파일을 받는 흐름.

시제품: 툴킷과 상관없이 배치와 꾸밈을 보는 화면(HTML 등). 발표자가 보고 고른다.

## Answer

시제품: `prototype/settings` 브랜치의 `tools/prototype_settings.html`(0660347). 세 안(A 사이드 탭 + 적용·취소, B 준비 체크리스트, C 대본 작업대 + 설정 서랍) 중 **B**를 골랐다.

- **되돌린 것**: 파일과 대본을 설정 창에서 빼서 📂 위성 버튼으로 여는 별도 창으로 옮겼었다(b9a8aef, 원 버튼 시제품 0315779). 발표자가 다시 생각해 되돌려 설정 창에서 다루기로 했다(0660347, 원 버튼 시제품 e1fc8b7). 그래서 위성 버튼은 다섯 개 그대로다.
- **설정 창**(⚙ 위성 버튼, 폭 약 720px):
  - 머리: 고른 강아지가 앉아 있고, "발표 준비 n / 4"와 칩 네 개와 코랄 진행 막대가 있다.
  - 접히는 카드 네 장:
    1. 발표 자료: 파일 이름과 요약, [다른 파일…], [📝 대본 열기], PowerPoint 연동 켜기와 상태(연결됨·꺼짐·끊김), 읽을 내용. 파일이 없으면 [파일 열기…]와 연동 켜기만 보인다.
    2. 목소리: 목소리와 [들어 보기], 출력 장치, 자동 발표, 쇼에서 바로 읽기, "배속은 원 버튼에서" 안내
    3. 질의응답: 제공자(Claude/OpenAI/Gemini 단추 묶음), 모델(기본 표시, 직접 입력 가능), API 키(보기·[확인]·결과 표시), 개인 지침, 캡션 켜기(기본 꺼짐)
    4. 캐릭터와 화면: 강아지 세 마리 카드(시바 기본), 강아지 보이기, 원 버튼 모니터
  - 카드 머리에는 지금 값의 요약이 보인다. 아직 안 된 첫 카드에 "다음 할 일" 표시를 달고, 처음 실행 때는 그 카드만 펼친다.
- **대본 창**(발표 자료 카드의 [📝 대본 열기], 폭 약 1020px):
  - 위: 슬라이드 카드 줄(제목, 첫 줄, ✎ 고친 대본, 🖼 그림 수)
  - 가운데: 고른 장의 대본 고치기와 [원래 내용으로]
  - 오른쪽: 캡션 진행 막대([멈추기]·[다시 만들기]), 발표자 노트, 그림마다 캡션 보기·고치기(건너뛴 그림은 이유 표시)
- **저장**: 바꾸면 바로 저장하고 "저장됨"을 잠깐 띄운다. 적용·취소는 없다. API 키는 [확인]을 누르거나 칸을 벗어날 때 저장한다.
- **처음 실행**: 프로그램을 처음 켜면 강아지가 기뻐하는 자세와 함께 설정 창이 저절로 열리고, 발표 자료 카드가 "다음 할 일"로 펼쳐진다. 그다음부터는 원 버튼의 [설정]으로만 연다.
- **꾸밈**: 오션·코랄. 바탕은 물빛(#E6F7F8)에서 흰색으로 흐르고, 주요 단추·켜진 스위치·진행 막대는 코랄 그라데이션, 글자는 깊은 바다색(#0B3A53)이다. Qt에서는 스타일시트로 옮긴다.
