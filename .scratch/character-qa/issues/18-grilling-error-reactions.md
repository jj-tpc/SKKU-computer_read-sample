# 오류가 났을 때 캐릭터의 반응 정하기

Type: grilling
Status: resolved

## Question

LLM 요청이 실패하면 캐릭터는 무엇을 말하고 어떻게 움직이나? 오류는 [LLM을 SDK로 부르나, 직접 HTTP로 부르나](12-grilling-llm-client.md)에서 정한 다섯 가지 공통 종류로 온다. 키 문제, 요금·한도, 연결 끊김, 시간 초과, 기타다.

정할 것:
- **종류마다 하는 말**: 말풍선에 띄우는 글과 음성으로 하는 말. 청중 앞이라는 점을 생각한다. 오류 내용을 청중에게 다 보여 주나, 발표자만 알게 하나.
- **자세와 원 버튼**: 강아지가 어떤 자세를 하나(새 자세가 필요한가). 원 버튼 파동은 어떻게 보이나.
- **느린 답**: 생각 중이 길어질 때 몇 초 뒤에 무엇을 하나. 시간 초과는 몇 초인가.
- **다시 하기**: 발표자가 같은 질문을 다시 보내는 방법. 질문창에 질문이 남아 있나.
- **답 도중 끊김**: 답을 말하던 중에 연결이 끊기면 이미 말한 부분은 어떻게 하나.
- **질의응답 밖의 오류**: 캡션 만들기, 키 확인, PowerPoint 연동, 음성 합성이 실패하면 어디에 알리나(설정 창인가, 캐릭터인가).

## Answer

원 버튼은 쇼가 뜬 모니터에 있으므로, 그 근처에 띄우는 글은 청중도 본다. 그래서 오류는 두 층으로 알린다. 강아지는 청중이 듣기 편한 짧은 말을 하고, 알림 줄은 발표자가 고칠 원인과 할 일을 짧게 띄운다.

- **알림 줄**: 원 버튼 왼쪽 위에 6초 동안 뜨는 작은 글.
- **질의응답 오류**: 강아지는 말풍선과 목소리로 말한다(운영체제 음성이라 인터넷이 끊겨도 나온다).

| 오류 | 강아지가 하는 말 | 알림 줄 |
|---|---|---|
| 키 문제 | "앗, 제 열쇠가 맞지 않아요." | API 키가 없거나 틀렸어요. 설정에서 확인하세요. |
| 요금·한도 | "오늘은 대답을 너무 많이 했나 봐요. 잠깐 쉬었다가 다시 물어봐 주세요." | 요금 한도나 사용량 제한에 걸렸어요. |
| 연결 끊김 | "인터넷이 끊긴 것 같아요." | 인터넷 연결을 확인하세요. |
| 시간 초과 | "생각이 너무 길어졌어요. 다시 물어봐 주시겠어요?" | 답이 늦어요. 생각 깊이를 낮춰 보세요. |
| 기타 | "앗, 문제가 생겼어요." | 제공자가 보낸 오류의 첫 줄 |

- **자세와 원 버튼**: 새 자세는 만들지 않는다. 오류를 말할 때는 말하기 자세에 땀방울 덧그림(생각 중의 구름처럼 얹는 그림)을 더한다. 원 버튼은 0.4초 동안 좌우로 살짝 흔들린 뒤 평상시로 돌아가고, 코랄 색은 그대로다.
- **느린 답**: 첫 글자를 기다리는 동안 생각 중 자세를 유지한다. 8초에 "조금만 기다려 주세요", 30초에 "아직 생각하고 있어요"를 한 번씩 말한다.
- **시간 초과**(발표자가 처음 제안보다 늘림):
  - 첫 글자까지: low 45초, mid 90초, high 150초
  - 답이 오다가 멈췄을 때: 30초
- **다시 묻기**: 오류가 나면 방금 보낸 질문을 질문창에 다시 채워 둔다. 성공하면 질문창을 비운다.
- **답하다가 끊김**: 이미 만든 문장까지는 끝까지 말하고, 이어서 "앗, 말하다가 연결이 끊겼어요"라고 말한다. 대화 기억에는 끊긴 답을 "(끊김)" 표시와 함께 남겨서 "계속해 줘"를 물을 수 있게 한다.
- **질의응답 밖의 오류**:

| 오류 | 알리는 곳 |
|---|---|
| 캡션 만들기 실패 | 대본 창의 캡션 진행 상황에만 표시한다(발표 중에는 알리지 않음). |
| 키 확인 실패 | 설정 창의 키 칸 옆에 표시한다. |
| PowerPoint 연동이 끊김 | 알림 줄에 "PowerPoint 연결이 끊겼어요"를 띄우고 자동 발표를 멈춘다. 설정 창의 연동 칸에도 표시한다. |
| 음성 합성 실패 | 말풍선 글만 보여 주고, 알림 줄에 "목소리를 낼 수 없어요. 출력 장치를 확인하세요."를 띄운다. |

## Comments

- 2026-10-16 발표자 답: Q1(강아지의 짧은 말 + 원 버튼 옆 알림 줄), Q2(새 자세 없이 말하기 자세에 땀방울 덧그림, 원 버튼은 0.4초 흔들림), Q4(오류 때 질문을 질문창에 다시 채움), Q5(만든 문장까지 말하고 끊김을 알림, 기억에는 "(끊김)"으로 남김), Q6(질의응답 밖 오류를 알리는 곳)을 추천대로 정했다. Q3은 "시간 초과가 너무 짧다, 더 늘려도 된다"고 해서 수치를 다시 묻는다.
