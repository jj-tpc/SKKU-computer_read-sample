# 캡션을 언제 만들고 어디에 두나

Type: grilling
Status: resolved
Blocked by: 03, 05

## Question

[세 LLM 제공자의 현재 모델과 생각 깊이 설정](03-research-llm-providers.md)과 [슬라이드 속 그림을 LLM에 보여 줄 이미지로 꺼내는 방법](05-research-slide-images.md)의 조사 결과를 보고, 캡션을 어떻게 다룰지 정한다.

정할 것:
- **무엇을 보여 주나**: 그림 개체만인가, 슬라이드 전체 그림인가, 도표는 데이터를 글로 넘기나.
- **언제 만드나**: 파일을 열 때 자동으로인가, 발표자가 버튼을 눌러서인가. 발표 자료가 바뀌면 다시 만드나.
- **어디에 두나**: 발표 파일 옆의 파일인가, 설정 폴더인가. 다음 실행 때 다시 쓰나.
- **고칠 수 있나**: 대본 창에서 캡션을 보고 고칠 수 있나.
- **쓰임**: 질의응답 근거로만 쓰나, 슬라이드를 읽을 때 대본에도 넣나. 조사에서 도표 값과 SmartArt 글은 LLM 없이 글로 꺼낼 수 있다는 것과, 지금 대본에는 둘 다 빠져 있다는 것이 드러났다. 이 둘을 대본과 질의응답 근거에 어떻게 넣을지도 함께 정한다.
- **비용 상한**: 그림이 많은 자료에서 비용과 시간을 어떻게 제한하나.

## Answer

**캡션은 만들되, 설정에서 켜고 끄며 기본값은 꺼짐이다.** 근거: [슬라이드 속 그림을 LLM에 보여 줄 이미지로 꺼내는 방법](05-research-slide-images.md), [질의응답 때 LLM에 무엇을 어떻게 넘기나](08-grilling-qa-prompt.md).

- **보여 주는 단위**: 슬라이드마다 그 장에서 꺼낸 그림들(python-pptx + Pillow)과 그 장의 글을 함께 보내서 그림마다 설명을 받는다.
  - 빼는 그림: 아주 작은 그림, 세 장 넘게 반복되는 로고·장식 그림.
  - 꺼내지 못한 그림(SVG만 있는 것, 도형을 모아 그린 것, macOS의 EMF/WMF 등)이 있는 슬라이드는 그 그림을 건너뛴다.
- **언제 만드나**: 캡션이 켜져 있고 키가 있을 때만 만든다.
  - 파일을 열면 뒤에서 저절로 만든다. 열린 파일이 있을 때 캡션을 켜도 바로 시작한다.
  - 바뀐 그림만 다시 만든다.
  - 대본 창에 진행 상황, 멈추기, "다시 만들기"를 둔다.
- **저장**: 프로그램 설정 폴더에 저장하고 그림 내용의 해시로 찾는다. 파일 이름을 바꾸거나 옮겨도 다시 쓰고, 발표 파일 옆에는 아무것도 만들지 않는다.
- **고치기**: 대본 창에서 슬라이드마다 캡션을 보고 고칠 수 있다. 고친 캡션은 "다시 만들기"를 해도 덮어쓰지 않는다.
- **쓰임**: 질의응답 근거에만 넣고 소리 내어 읽지 않는다.
- **형식**: 그림마다 한국어 1~3문장. 그림 속 글자와 숫자는 그대로 옮긴다.
- **상한**: 파일 하나에 그림 40개까지 보낸다(넘으면 대본 창에 알림). 그림은 긴 변 1024px로 줄여 보낸다. 생각 깊이는 늘 low이고, 모델은 질의응답과 같은 것을 쓴다.
- **이번에 빼는 것**: 도표 값과 SmartArt 글을 꺼내 넣는 일, 꺼내지 못한 그림이 있는 슬라이드를 Windows 연동으로 통째 내보내 보충하는 일(지도의 범위 밖). 슬라이드 안의 표는 지금 코드가 이미 글로 읽는다.
