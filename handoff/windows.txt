슬라이독 (Windows) — 먼저 읽어 주세요
======================================

1. 압축을 풀고 Slidog 폴더째 원하는 곳에 둡니다. 폴더 안의 파일을 따로 옮기지 마세요.
2. Slidog.exe를 두 번 누릅니다.
   - 이 프로그램은 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다.
     [추가 정보]를 누른 뒤 [실행]을 누르세요. 한 번만 하면 됩니다.
3. 처음 켜면 강아지가 기뻐하고 설정 창이 열립니다. 위에서부터 차례로 준비하세요.
   - 발표 자료: [파일 열기…] 또는 PowerPoint에 자료를 열고 연동을 켭니다.
     처음에는 함께 든 "예제 발표 자료.pptx"로 해 볼 수 있습니다.
   - 질의응답: AI 제공자를 고르고 API 키를 넣은 뒤 [확인]을 누릅니다.
4. 화면 오른쪽 아래의 코랄빛 원 버튼을 누르면 위성 버튼(질문하기, 읽기/정지, 배속, 설정, 끝내기)이 펼쳐집니다.

설정과 고친 대본은 %APPDATA%\슬라이독 폴더에 저장됩니다(옛 이름 PPT읽어주기 폴더가 있으면 처음 켤 때 옮겨 옵니다). API 키도 이 파일에 그대로 저장되니, 다른 사람과 함께 쓰는 컴퓨터라면 다 쓴 뒤 설정에서 키를 지우세요.
