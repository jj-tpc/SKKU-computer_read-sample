슬라이독 (macOS, Apple Silicon) — 먼저 읽어 주세요
===================================================

설치
----
1. macOS 판이 15(Sequoia) 이상인지 확인합니다. 사과 메뉴 › 이 Mac에 관하여에서 봅니다.
   15보다 낮으면 실행되지 않습니다. M1 Pro는 소프트웨어 업데이트로 올릴 수 있습니다.
2. 받은 zip을 Finder에서 두 번 눌러 풀고, Slidog.app을 응용 프로그램 폴더로 옮깁니다.
   (다른 압축 프로그램으로 풀면 앱이 깨질 수 있습니다)
3. Slidog를 엽니다. 이 프로그램은 Apple 서명·공증이 없어서 처음에는 열리지 않고 경고가 뜹니다.
   경고를 닫은 뒤 시스템 설정 › 개인정보 보호 및 보안으로 가서 아래쪽의 [그래도 열기]를 누르고, 다시 한 번 [열기]를 누릅니다.
   - [그래도 열기] 단추는 열려고 한 뒤 약 1시간 동안만 보입니다.
   - macOS 15부터는 Control-클릭 › 열기로 넘어가는 방법이 없습니다.
   - [그래도 열기]가 보이지 않거나 "손상되었기 때문에 열 수 없습니다"가 뜨면,
     터미널(응용 프로그램 › 유틸리티 › 터미널)에서 아래 한 줄을 실행한 뒤 다시 엽니다.
       xattr -dr com.apple.quarantine /Applications/Slidog.app
4. PowerPoint 연동을 켜면 "PowerPoint를 제어하려고 합니다"라는 창이 뜹니다. [허용]을 누릅니다.
   (나중에 바꾸려면 시스템 설정 › 개인정보 보호 및 보안 › 자동화)
5. 새 판을 받을 때마다 2~4를 다시 합니다. 서명이 없어서 macOS가 새 판을 다른 앱으로 알아보기 때문에, 자동화 허용도 다시 묻습니다.

처음 써 보기
------------
1. 처음 켜면 강아지가 기뻐하고 설정 창이 열립니다.
2. 발표 자료 카드의 [파일 열기…]로 함께 받은 "예제 발표 자료.pptx"를 엽니다.
   내 자료를 PowerPoint 쇼로 띄워 쓰려면, PowerPoint에서 자료를 열고 연동을 켭니다.
3. 화면 오른쪽 아래의 코랄빛 원 버튼을 누르면 위성 버튼(질문하기, 읽기/정지, 배속, 설정, 끝내기)이 펼쳐집니다.
   [▶]를 누르면 강아지가 대본을 소리 내어 읽습니다.
4. 질의응답은 AI 키가 있어야 합니다. 질의응답 카드에서 제공자(Claude, OpenAI, Gemini)를 고르고
   API 키를 넣은 뒤 [확인]을 누릅니다. 키가 없어도 대본 읽기는 됩니다.

확인표 (결과를 사진으로 보내 주세요)
-----------------------------------
1. macOS 판이 15 이상이다. (이 Mac에 관하여 창 사진)
2. 실제 PowerPoint 슬라이드 쇼를 띄웠을 때, 쇼 위에 강아지와 원 버튼이 보인다. (화면 사진)
3. 레티나 화면에서 강아지와 원 버튼의 크기와 위치가 알맞다(원 버튼은 화면 오른쪽 아래 구석). (화면 사진)
4. 대본 읽기, 질의응답(질문을 치고 Enter), 말풍선이 된다. 질문창을 Esc로 닫으면 쇼가 다시 키 입력을 받는다.
   원 버튼과 [읽기]·[배속]을 여러 번 눌러도, 쇼가 방향키(또는 리모컨)로 계속 넘어간다.
5. 터미널을 열고 아래 명령을 실행한 결과를 보내 주세요. 모든 줄이 OK여야 합니다.
     /Applications/Slidog.app/Contents/MacOS/Slidog --self-check

설정과 고친 대본은 ~/Library/Application Support/슬라이독 폴더에 저장됩니다(옛 이름 PPT읽어주기 폴더가 있으면 처음 켤 때 옮겨 옵니다). API 키도 이 파일에 그대로 저장됩니다.
